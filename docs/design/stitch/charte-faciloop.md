# Charte retenue (Faciloop)
- Couleur principale : #FF8A3D (hsl 24 100% 62%) : boutons d'action, états actifs, focus.
- Texte sur l'orange : #1A1A1A (contraste 7,4:1). Le blanc sur cet orange est illisible (2,35:1) : interdit.
- Orange utilisé comme texte sur fond clair : #C2410C.
- Mode clair : fond #FFFFFF, cartes blanches bordure hsl(0 0% 90%), texte #3A3A3A.
- Mode sombre : fond #121212, cartes #1A1A1A, bordures hsl(0 0% 20%), texte hsl(0 0% 95%).
- Arrondi 12 px. Classes sémantiques seulement (bg-background, text-foreground, bg-card, border-border, bg-primary).
- Dégradé orange → rose : un seul bouton par page au maximum.
- Les maquettes Stitch sont une inspiration : leurs chiffres et promesses (« #1 au Sénégal », « 45 000 festivaliers », « 0 % frais »…) sont faux et ne doivent jamais apparaître.
