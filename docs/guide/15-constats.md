# 15 — Constats : écarts relevés en écrivant le guide

> Tout écart trouvé en écrivant le guide entre ce que l'écran dit et ce que le code fait, texte incohérent, bouton sans
> effet, message manquant ou en double. **Aucune correction du code n'a été faite.** Source de vérité : le code de main
> `0889df6`. `M/` = `supabase/migrations/`. Chemins relatifs au dépôt.
>
> Les rédacteurs ont noté leurs écarts sous des identifiants de travail W1-xx à W8-xx, que les fichiers 01 à 14 citent
> encore (« constat W6-02 ») ; la colonne **Note** donne la correspondance. Les notes en double ont été fusionnées : 111
> notes de travail donnent **96 constats G** ; la passe de cohérence en a reclassé un après relecture du code (G-30) et élargi
> un autre (G-31, règle de mot de passe de l'activation d'un contrôleur ; G-45, troisième libellé du SUPERADMIN).
>
> **Gravité.** *Bloquant* : empêche un parcours prévu ou expose un droit ou de l'argent sans contournement — **aucun**
> constat ne l'est. *Visible* : l'écran ou un message dit autre chose que ce que fait le code, ou un essai de la recette
> échoue sur ce point. *Mineur* : texte, libellé, cas rare, code sans écran ou commentaire en retard. « À arbitrer » :
> le code est cohérent, le choix reste à faire.
